# Ingestion Service

Ingests competitor social posts. v1 uses a fixture-backed connector interface (no live scraping/paid API integration yet) so the rest of the pipeline can be built and tested against realistic data.

## API

- `GET /health` — liveness check.
- `POST /ingest/run` — runs the fixture connector, upserts accounts/posts, returns counts (idempotent — re-running skips posts already ingested by `external_post_id`).
- `GET /accounts` — list ingested competitor accounts.
- `GET /posts` — list ingested competitor posts, including computed `engagement_score` and parsed `themes`.

Full interactive contract (Swagger UI, auto-generated by FastAPI) is at `/docs` when the service is running.

## Run standalone

```bash
cd services/ingestion
uv sync
cp .env.example .env
uv run uvicorn app.main:app --reload --port 8001
```

## Env vars

See [.env.example](.env.example). `DATABASE_URL` is the only one required to run standalone.

## Tests

```bash
uv run pytest
```
